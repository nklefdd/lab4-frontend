# Jewelry Store — фронтенд

Простий фронтенд для онлайн-крамниці ювелірних прикрас. Він показує каталог прикрас, який отримує з REST API бекенду, і дозволяє відфільтрувати його за категорією. Мета: показати, що фронтенд на іншому порту успішно звертається до API завдяки CORS.

Зроблено на чистих HTML, CSS і JavaScript (`fetch`), без збирання й залежностей.

Бекенд-репозиторій: _посилання на бекенд_

## Як запустити проєкт

Спочатку запустіть бекенд за інструкцією з його README (`python manage.py runserver`). Потім:

1. Клонуйте цей репозиторій і перейдіть у його папку.
2. Запустіть будь-який статичний сервер **на порту 5500**, наприклад:

   ```bash
   python -m http.server 5500
   ```

   Або відкрийте папку у VS Code і натисніть Go Live (розширення Live Server за замовчуванням працює на порту 5500).

3. Відкрийте в браузері `http://127.0.0.1:5500`.

### Адреси та порти

| Частина | Адреса |
| --- | --- |
| Фронтенд | `http://127.0.0.1:5500` |
| Бекенд (API) | `http://127.0.0.1:8000/api` |

Бекенд дозволяє запити лише з `http://127.0.0.1:5500` і `http://localhost:5500` (налаштування `CORS_ALLOWED_ORIGINS`). Якщо запустити фронтенд на іншому порту, браузер заблокує запити, а сторінка покаже повідомлення про помилку. Не відкривайте `index.html` просто двічі клікнувши по файлу (`file://`), це теж не працюватиме.

Якщо бекенд працює за іншою адресою, змініть константу `API_URL` на початку `app.js`.

## Що вміє

- Завантажує категорії (`GET /api/categories`) і прикраси (`GET /api/products`).
- Показує прикраси картками: категорія, назва, опис, ціна, метал і наявність.
- Фільтрує прикраси за категорією.
- Показує повідомлення, якщо каталог порожній або сервер недоступний.
